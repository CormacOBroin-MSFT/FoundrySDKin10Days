TITLE
Query and Filter Data Using Microsoft Foundry SDK

OBJECTIVE
Use the Microsoft Foundry SDK to query a dataset and filter the results based on specific criteria.

PROGRAMMING CONCEPTS PRACTICED
- Basic SDK integration
- Variable assignment
- Conditional statements
- List operations
- String handling

REQUIREMENTS
- Write a Python script that integrates with the Microsoft Foundry SDK.
- Query a dataset using the SDK to retrieve a list of items.
- Filter the items to include only those that match a specific condition (e.g., a field that contains a certain string).
- Store the filtered results in a new list.
- Output the filtered list to the console.

EXPECTED BEHAVIOR
- The script correctly queries the dataset using the Microsoft Foundry SDK.
- The script processes the response to filter items based on the specified condition.
- The script outputs the filtered list to the console.

DIFFICULTY RATING (0-9)
2
