TITLE
Weather Fetcher with Foundry SDK

OBJECTIVE
Use the Foundry SDK to fetch weather data and process the response to display the temperature for a given city.

PROGRAMMING CONCEPTS PRACTICED
- Working with external SDKs
- Making API calls
- Parsing JSON data in Python
- Conditional statements
- Basic string handling

REQUIREMENTS
- Use the Microsoft Foundry SDK to fetch weather data for a specified city.
- Extract and display the temperature from the response.
- If the temperature is above a certain threshold (e.g., 75°F), print "It's hot in [City]!" otherwise print "The weather is mild in [City]."
- Ensure the program handles basic errors such as missing city data or invalid responses.

EXPECTED BEHAVIOR
When run, the script should:
1. Prompt the user for a city name.
2. Fetch the weather data using the Foundry SDK.
3. Parse the JSON response to extract the temperature.
4. Display the temperature along with a message based on the provided threshold (e.g., hot or mild weather).
